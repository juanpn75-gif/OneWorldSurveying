Instructions

  1. Set tolerances on the Project tab.
  2. Import a baseline CSV or manually enter each monitoring target and its baseline northing, easting, and elevation.
  3. Enter the current point-number mapping. If field descriptions already equal the target names, enter the description and leave point blank.
  4. Import the current CSV, PNEZD/TXT, or RW5 file. Review duplicates and field QC warnings.
  5. Open Results. Red rows exceed either the horizontal or vertical threshold; yellow rows were not observed.
  6. After review, commit the survey to history. Use Print / Save PDF for a client report and Export CSV for the calculation record.
  7. Export a JSON backup regularly. Browser storage can be cleared by IT settings or browser maintenance.

Supported coordinate records

CSV with named columns; P,N,E,Z,D comma records; common space-delimited PNEZD; and Carlson RW5 stored-point records beginning with SP. The RW5 validation scanner also flags zero instrument heights and recognizable horizontal/vertical check values above the project QC limits.

Professional review required. This tool assists computation and QA/QC. Confirm control stability, mapping, field procedures, coordinate units, signs, thresholds, and report content before issuing results.
