Independent Remote Pilot Study App

Part 107 Practice Exam

100 original questions for certification study, including a 60-question timed UAG-style simulation and an extra survey-flight application section.

Build a practice session

The FAA UAG knowledge test contains 60 questions, allows 2 hours, and has a 70% passing score. This app’s timed simulation uses 60 original multiple-choice questions mapped to FAA ACS areas; survey-flight questions are separate study practice. This is not an FAA exam or question bank. The app uses four-option questions only and does not reproduce FAA questions or figure-based test items. Timer runs continuously. Scores save on this device.
