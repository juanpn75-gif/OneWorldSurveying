❓ How to Use This App

Convert a KMZ or KML file

  1. Stay on the KMZ/KML File tab and drag a file into the drop area, or select it with the file picker.
  2. Choose the State Plane zone. Automatic by location can select among the supported NJ, NY, and PA zones, or you can force a specific zone.
  3. Choose output units, coordinate order, decimal places, elevation handling, and the starting point number.
  4. Press Convert if needed, then review the coordinate table and conversion summary.
  5. Export the results as CSV, PNEZD TXT, or DXF.

Convert manual coordinates

  1. Select the Manual Coordinates tab.
  2. Enter one point per line as Name, Longitude, Latitude, Elevation. Longitude comes before latitude.
  3. Press Load Manual Coordinates.
  4. Set the same conversion options, review the projected results, and export in the format you need.

Supported State Plane systems

  • New Jersey — EPSG:3424.
  • New York East, Central, West, and Long Island — EPSG:2260 through 2263.
  • Pennsylvania North and South — EPSG:2271 and EPSG:2272.
Important: KML/KMZ coordinates are read in KML order: longitude, latitude. The app keeps the source geographic precision for projection even though latitude and longitude are displayed to 6 decimals. Confirm the correct State Plane zone and units before using exported coordinates in CAD or survey work.
