Rational Method: Q = C i A
Continuity: Q = A V
Manning (U.S.): Q = (1.486/n) A R^(2/3) S^(1/2)
Hydraulic radius: R = A / Pw; full circular pipe: R = D/4
Classic TR-55: S = 1000/CN - 10; Ia = 0.2S; runoff depth Q = (P-Ia)²/(P-Ia+S), for P > Ia
Slope = vertical fall / horizontal length; percent slope = slope × 100
