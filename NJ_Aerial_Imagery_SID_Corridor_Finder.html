2. SID result

Enter a location or route corridor to identify the required SID tile(s).
Created by Juan A. Pichardo. Route corridor source: NJDOT New Jersey Standard Route ID and Milepost ArcGIS feature service. Tile index source: Index.dxf. SID imagery source: NJOGIS 2020 MrSID (MG3), public HTTPS/AWS S3 imagery bucket. Individual tile objects are stored as <TileID>.zip. Downloads are browser-only; no PowerShell, BAT, or AWS CLI is used. The file contains 9,201 indexed 5,000-ft square footprints. Index coordinate system used by this app: NAD83 / New Jersey (US survey foot), EPSG:3424. Address geocoders normally return WGS84-style latitude/longitude; this app projects them with the GRS80/NAD83 State Plane parameters. Near a tile edge, use the adjacent-tile warning as the safer check. The background map has built-in map logic (no external JavaScript library) and uses Esri World Street Map or Esri World Imagery. Background tiles require an internet connection; coordinate conversion and SID tile calculations remain offline.
