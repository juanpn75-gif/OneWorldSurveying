NJ Aerial Imagery & SID Corridor Finder

Find individual 5,000 × 5,000 ft SID imagery tiles — or every SID tile required along a New Jersey highway milepost corridor.

Version 2.1 · Created by Juan A. Pichardo
❓ How to Use This App

Find one SID tile

  1. Choose Address, Lat / Long, or NJ State Plane.
  2. Enter the location. State Plane values are entered as Easting and Northing in US survey feet.
  3. Set the adjacent-tile edge tolerance if you want nearby tiles flagged when the point is close to a tile boundary.
  4. Press Find SID tile. Review the tile ID, map, and any adjacent-tile warning before downloading.

Find tiles for a highway corridor

  1. Select Route Corridor.
  2. Enter the NJ route number and the beginning and ending mileposts.
  3. Enter the corridor buffer on each side of the route centerline. A value of 0 ft selects only tiles crossed by the route.
  4. Use Advanced route alignment only when you need to override the automatically built NJDOT SRI.
  5. Press Find corridor SID tiles, review the list and map, then download the required tile ZIP files.

Input notes

  • Latitude/longitude accepts decimal degrees and common degree-minute-second style entries.
  • The SID index is NAD83 / New Jersey State Plane, US survey foot, EPSG:3424.
  • Address lookup, Route Corridor lookup, map backgrounds, and SID downloads require an internet connection. Coordinate and State Plane tile calculations can work offline.
Survey tip: If a point falls near a tile edge, include the adjacent tile shown by the app. For corridor work, use enough buffer to cover the actual mapping or survey limits rather than relying only on the route centerline.

Created by Juan A. Pichardo. Route corridor source: NJDOT New Jersey Standard Route ID and Milepost ArcGIS feature service. Tile index source: Index.dxf. SID imagery source: NJOGIS 2020 MrSID (MG3), public HTTPS/AWS S3 imagery bucket. Individual tile objects are stored as <TileID>.zip. Downloads are browser-only; no PowerShell, BAT, or AWS CLI is used. The file contains 9,201 indexed 5,000-ft square footprints. Index coordinate system used by this app: NAD83 / New Jersey (US survey foot), EPSG:3424. Address geocoders normally return WGS84-style latitude/longitude; this app projects them with the GRS80/NAD83 State Plane parameters. Near a tile edge, use the adjacent-tile warning as the safer check. The background map has built-in map logic (no external JavaScript library) and uses Esri World Street Map or Esri World Imagery.
